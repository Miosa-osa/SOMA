# SOMA brand

SOMA is the Secure Optimized Machine Architecture by MIOSA.
The product and public repository name are written as `SOMA`.
Commands, package names, and source paths use lowercase `soma` where required by platform convention.

## Endorsed lockup

Use the MIOSA wordmark above the SOMA product name when space permits.
Use the MIOSA orb alone for square avatars, favicons, and compact product surfaces.
Do not stretch, skew, recolor, outline, rotate, or place effects over the supplied artwork.

The checked-in assets came from the MIOSA brand kit supplied by the project owner.
Only transparent outer padding was trimmed from the source PNG files.
No generative model was used to redraw or reinterpret the marks.

## Assets

- `assets/brand/miosa-icon.png` is the compact MIOSA orb.
- `assets/brand/miosa-logo-black-text.png` is the wordmark for light backgrounds.
- `assets/brand/miosa-logo-white-text.png` is the wordmark for dark backgrounds.

README and documentation surfaces should use a color-scheme-aware `<picture>` element so the correct wordmark is selected automatically.
Terminal output should use the plain `SOMA` name and must not emit decorative banners in JSON mode or on every command invocation.

## Accessibility

Every use of a brand image must include meaningful alternative text unless it is purely decorative.
Keep sufficient contrast around the mark and preserve a clear area of at least one quarter of the mark's height.
Do not encode lifecycle, security, or failure status through the logo or color alone.
